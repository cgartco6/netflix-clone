# Netflix Clone Monorepo

Self-hosted cross-platform media engine that automatically mounts external HDDs/SSDs, fetches metadata, streams IPTV channels, and serves mobile, web, and TV clients.

## Quick Start Guide

### 1. Mount Drives
Run the mount script as root to discover and mount attached storage:
```bash
sudo chmod +x scripts/mount-drives.sh
sudo ./scripts/mount-drives.sh
